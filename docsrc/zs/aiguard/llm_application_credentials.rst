llm_application_credentials
===========================

The following methods allow for interaction with the Zscaler AI Guard LLM Application Credentials API endpoints.
Includes listing, creating, updating, deleting, and regenerating LLM application credentials, retrieving a credential by ID or name, and running referential checks.

Methods are accessible via ``aiguard.llm_application_credentials``
