policy_match_rules
==================

The following methods allow for interaction with the Zscaler AI Guard Policy Match Rules API endpoints.
Includes listing, creating, updating, and deleting policy match rules, and retrieving a rule by ID or name.

Methods are accessible via ``aiguard.policy_match_rules``
