llm_applications
================

The following methods allow for interaction with the Zscaler AI Guard LLM Applications API endpoints.
Includes listing, creating, updating, and deleting LLM applications, retrieving an application by ID or name, and running referential checks.

Methods are accessible via ``aiguard.llm_applications``
